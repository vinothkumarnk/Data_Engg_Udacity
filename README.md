# Data Modeling for ACME

Udacity ND027 (Data Engineering with AWS) Course 1 capstone project — designing data models across ACME Corporation's stack.

- **part1_postgres/** — normalized OLTP schema for ACME Corp's legacy e-commerce system (wholesalers ordering gears)
- **part2_mongodb/** — flexible/unstructured schema for ACME 3D Printing, the subsidiary
- **part3_neo4j/** — graph schema for ACME 3D Printing's product recommendation engine (customers, products, purchases)
